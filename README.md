# DS1202 – Linux System Information Project

## 📌 Project Description

The Linux System Information Project is a Bash scripting project
that collects and displays useful information about a Linux system.

## ✨ Features

- 📅 Displays the current date and time
- 💻 Shows the system hostname
- 🐧 Displays OS and kernel details
- 🧠 Reports RAM usage
- 💾 Shows disk space information
- ⚙️ Reports CPU load
- ⏱️ Displays system uptime
- 📝 Saves system reports with timestamps
