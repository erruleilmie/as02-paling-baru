DS1202 Linux System Information
Project Description
This project uses a Bash script to collect and display useful information about a Linux system.
Features
Displays the current date and time
Shows the system hostname
Provides OS and kernel details
Displays RAM usage
Shows disk space information
Reports CPU load and system uptime
Saves system reports with timestamps
Project Structure
scripts/sysinfo.sh - Main script for checking system information
docs/ - Stores documentation
logs/ - Stores generated system reports
How to Run
Execute the following command in the terminal:
./scripts/sysinfo.sh
